**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `grab`, `squeeze`, `controller`

Grab and release small cubes with the grip button.

## Run it

Open the launcher and pick **Grab Objects**, or deep-link straight to it:

```
http://localhost:5173/#grab-objects
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
