# Gaze Select

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `gaze`, `dwell`, `select`, `camera`

Objects fill a progress ring and trigger when looked at for ~1.5 s.

## Run it

Open the launcher and pick **Gaze Select**, or deep-link straight to it:

```
http://localhost:5173/#gaze-select
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
