# AR Hit-Test

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `hit-test`, `reticle`, `placement`

Requests a hit-test source and places a reticle on detected surfaces; tap to drop a marker.

## Run it

Open the launcher and pick **AR Hit-Test**, or deep-link straight to it:

```
http://localhost:5173/#ar-hit-test
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
