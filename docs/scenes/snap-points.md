# Snap Points

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `snap`, `drag`, `grab`, `controller`

Draggable pieces that snap to the nearest of several socket positions when released.

## Run it

Open the launcher and pick **Snap Points**, or deep-link straight to it:

```
http://localhost:5173/#snap-points
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
