# UI Toggle

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `toggle`, `light`

A Toggle3D switch that turns a point light on and off; auto-cycles on desktop.

## Run it

Open the launcher and pick **UI Toggle**, or deep-link straight to it:

```
http://localhost:5173/#ui-toggle
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
