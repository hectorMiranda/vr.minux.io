# Transmission Glass

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `glass`, `transmission`, `ior`, `physical`

A MeshPhysicalMaterial glass sphere with transmission/IOR/thickness over a colourful procedural backdrop.

## Run it

Open the launcher and pick **Transmission Glass**, or deep-link straight to it:

```
http://localhost:5173/#transmission-glass
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
