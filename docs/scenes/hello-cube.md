# Hello Cube

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `mesh`, `basics`

A single rotating cube — the smallest possible scene.

## Run it

Open the launcher and pick **Hello Cube**, or deep-link straight to it:

```
http://localhost:5173/#hello-cube
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
