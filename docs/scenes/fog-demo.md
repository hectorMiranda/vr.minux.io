# Fog Demo

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `fog`, `linear-fog`, `exp-fog`, `atmosphere`

A corridor of pillars under animated linear and exponential fog; the mode switches every 5 s and density breathes continuously.

## Run it

Open the launcher and pick **Fog Demo**, or deep-link straight to it:

```
http://localhost:5173/#fog-demo
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
