# Wrist Menu

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `menu`, `controller`, `xr`

A Menu widget attached to the left controller grip, summoned by squeeze.

## Run it

Open the launcher and pick **Wrist Menu**, or deep-link straight to it:

```
http://localhost:5173/#wrist-menu
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
