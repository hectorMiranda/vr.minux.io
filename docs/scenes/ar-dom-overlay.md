# AR DOM Overlay

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `dom-overlay`, `ui`, `hud`

Uses a DOM overlay element to show AR controls and instructions over the camera feed; element is removed on dispose.

## Run it

Open the launcher and pick **AR DOM Overlay**, or deep-link straight to it:

```
http://localhost:5173/#ar-dom-overlay
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
