# Squeeze Grip

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `squeeze`, `grip`, `analog`, `input`

A stylized hand that closes its fingers proportionally to the squeeze/grip value.

## Run it

Open the launcher and pick **Squeeze Grip**, or deep-link straight to it:

```
http://localhost:5173/#squeeze-grip
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
