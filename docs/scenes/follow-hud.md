# Follow HUD

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `hud`, `camera`, `overlay`

A camera-attached HUD panel that displays live position and frame counter.

## Run it

Open the launcher and pick **Follow HUD**, or deep-link straight to it:

```
http://localhost:5173/#follow-hud
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
