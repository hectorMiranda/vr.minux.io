# Tube Knot

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `tube`, `curve`, `catmullrom`, `knot`

A TubeGeometry swept along a CatmullRomCurve3 trefoil path, gently spinning.

## Run it

Open the launcher and pick **Tube Knot**, or deep-link straight to it:

```
http://localhost:5173/#tube-knot
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
