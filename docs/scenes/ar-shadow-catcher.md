# AR Shadow Catcher

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `shadow`, `ShadowMaterial`, `shadow-catcher`, `lighting`

A ShadowMaterial ground plane catches the shadow of a hovering virtual object, blending it with the real floor.

## Run it

Open the launcher and pick **AR Shadow Catcher**, or deep-link straight to it:

```
http://localhost:5173/#ar-shadow-catcher
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
