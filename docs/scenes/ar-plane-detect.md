# AR Plane Detection

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `plane-detection`, `surfaces`, `mesh`

Visualizes WebXR-detected planes as translucent coloured polygons; shows mock planes on desktop.

## Run it

Open the launcher and pick **AR Plane Detection**, or deep-link straight to it:

```
http://localhost:5173/#ar-plane-detect
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
