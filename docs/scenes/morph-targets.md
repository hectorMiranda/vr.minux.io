# Morph Targets

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `morph`, `animation`, `shape`

A mesh with morph attributes smoothly blending between a sphere and a cube.

## Run it

Open the launcher and pick **Morph Targets**, or deep-link straight to it:

```
http://localhost:5173/#morph-targets
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
