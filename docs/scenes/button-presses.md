# Button Presses

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `button`, `gamepad`, `input`

Visualizes each gamepad button as a bar that fills and lights when pressed; auto-animates on desktop.

## Run it

Open the launcher and pick **Button Presses**, or deep-link straight to it:

```
http://localhost:5173/#button-presses
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
