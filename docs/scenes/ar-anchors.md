# AR Anchors

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `anchors`, `placement`, `hit-test`, `XRanchor`

Places objects using XRAnchors (when supported) so they stay fixed; falls back to world-space transforms; shows an anchor count label.

## Run it

Open the launcher and pick **AR Anchors**, or deep-link straight to it:

```
http://localhost:5173/#ar-anchors
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
