# Dash Move

**Category:** Locomotion &middot; **XR:** vr &middot; **Tags:** `locomotion`, `dash`, `easing`, `teleport`

Quick eased dash toward where the controller points using easeOutCubic.

## Run it

Open the launcher and pick **Dash Move**, or deep-link straight to it:

```
http://localhost:5173/#dash-move
```

## What this verifies

Verifies a locomotion technique and its comfort behaviour by moving the camera rig rather than the camera.
