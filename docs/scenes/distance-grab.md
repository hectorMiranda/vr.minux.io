# Distance Grab

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `grab`, `ray`, `select`, `controller`

Point the controller ray at a distant object and pull it in on select.

## Run it

Open the launcher and pick **Distance Grab**, or deep-link straight to it:

```
http://localhost:5173/#distance-grab
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
