# World Labels

**Category:** Text &middot; **XR:** vr &middot; **Tags:** `text`, `canvas`, `label`, `world-space`

Floating CanvasTexture labels rendered above world-space objects.

## Run it

Open the launcher and pick **World Labels**, or deep-link straight to it:

```
http://localhost:5173/#world-label
```

## What this verifies

Checks in-world text rendering via canvas textures stays crisp at VR resolutions.
