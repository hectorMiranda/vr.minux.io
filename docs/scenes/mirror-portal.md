# Mirror Portal

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `reflector`, `mirror`, `portal`, `addons`

A Reflector (three/addons) mirror panel in a decorated frame; falls back to a shiny MeshStandardMaterial if the addon is unavailable.

## Run it

Open the launcher and pick **Mirror Portal**, or deep-link straight to it:

```
http://localhost:5173/#mirror-portal
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
