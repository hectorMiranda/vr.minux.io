# Trail Ribbon

**Category:** Effects &middot; **XR:** vr &middot; **Tags:** `trail`, `ribbon`, `geometry`, `particles`

A moving emitter traces a Lissajous path and leaves a dynamic ribbon trail with color gradient from tail to head.

## Run it

Open the launcher and pick **Trail Ribbon**, or deep-link straight to it:

```
http://localhost:5173/#trail-ribbon
```

## What this verifies

Validates a real-time effect (particles, trails, soft-body or physics) under the XR render loop.
