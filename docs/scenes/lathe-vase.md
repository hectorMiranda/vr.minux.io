# Lathe Vase

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `lathe`, `vase`, `profile`, `geometry`

A ceramic-style vase built with LatheGeometry from a hand-crafted profile curve.

## Run it

Open the launcher and pick **Lathe Vase**, or deep-link straight to it:

```
http://localhost:5173/#lathe-vase
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
