# AR Reticle

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `reticle`, `hit-test`, `pulse`

Styled ring + crosshair reticle that follows hit-test poses with a pulsing animation.

## Run it

Open the launcher and pick **AR Reticle**, or deep-link straight to it:

```
http://localhost:5173/#ar-reticle
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
