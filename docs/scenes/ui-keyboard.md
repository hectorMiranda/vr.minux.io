# UI Keyboard

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `keyboard`, `input`, `text`

A 3D QWERTY key grid that appends characters to a canvas-label display.

## Run it

Open the launcher and pick **UI Keyboard**, or deep-link straight to it:

```
http://localhost:5173/#ui-keyboard
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
