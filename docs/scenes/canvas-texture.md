# Canvas Texture

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `canvas`, `texture`, `2d`, `animation`

A live 2D canvas animation (spirograph trails + particle swarm) streamed as a CanvasTexture onto a panel each frame.

## Run it

Open the launcher and pick **Canvas Texture**, or deep-link straight to it:

```
http://localhost:5173/#canvas-texture
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
