# PBR Materials

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `pbr`, `roughness`, `metalness`, `materials`

A 5×5 grid of spheres spanning roughness (rows) × metalness (cols) under a rotating three-point light rig.

## Run it

Open the launcher and pick **PBR Materials**, or deep-link straight to it:

```
http://localhost:5173/#pbr-materials
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
