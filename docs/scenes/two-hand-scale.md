# Two-Hand Scale

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `scale`, `two-hand`, `grab`, `controller`

Grab an object with both controllers and scale it by the distance between them.

## Run it

Open the launcher and pick **Two-Hand Scale**, or deep-link straight to it:

```
http://localhost:5173/#two-hand-scale
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
