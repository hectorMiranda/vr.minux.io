# Hover Highlight

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `hover`, `ray`, `highlight`, `controller`

Cubes that scale and tint when the controller ray (or auto-sweep on desktop) points at them.

## Run it

Open the launcher and pick **Hover Highlight**, or deep-link straight to it:

```
http://localhost:5173/#hover-highlight
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
