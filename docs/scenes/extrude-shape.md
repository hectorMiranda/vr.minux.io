# Extruded Star Shape

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `extrude`, `shape`, `bevel`, `star`

A 5-pointed star shape extruded with bevel using THREE.ExtrudeGeometry.

## Run it

Open the launcher and pick **Extruded Star Shape**, or deep-link straight to it:

```
http://localhost:5173/#extrude-shape
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
