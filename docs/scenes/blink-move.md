# Blink Move

**Category:** Locomotion &middot; **XR:** vr &middot; **Tags:** `teleport`, `locomotion`, `blink`, `fade`

Teleport with a fade-to-black blink overlay masking the position change.

## Run it

Open the launcher and pick **Blink Move**, or deep-link straight to it:

```
http://localhost:5173/#blink-move
```

## What this verifies

Verifies a locomotion technique and its comfort behaviour by moving the camera rig rather than the camera.
