# Trigger Pressure

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `trigger`, `analog`, `input`

A bar that fills proportionally to the analog trigger value for each controller.

## Run it

Open the launcher and pick **Trigger Pressure**, or deep-link straight to it:

```
http://localhost:5173/#trigger-pressure
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
