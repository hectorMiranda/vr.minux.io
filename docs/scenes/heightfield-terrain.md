# Heightfield Terrain

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `terrain`, `heightfield`, `vertex-colors`, `noise`

A plane displaced by layered sine noise into rolling terrain with elevation-based vertex colors.

## Run it

Open the launcher and pick **Heightfield Terrain**, or deep-link straight to it:

```
http://localhost:5173/#heightfield-terrain
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
