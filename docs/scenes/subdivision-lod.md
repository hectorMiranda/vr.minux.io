# Subdivision LOD

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `lod`, `subdivision`, `tessellation`

An icosahedron shown at five increasing tessellation levels side by side.

## Run it

Open the launcher and pick **Subdivision LOD**, or deep-link straight to it:

```
http://localhost:5173/#subdivision-lod
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
