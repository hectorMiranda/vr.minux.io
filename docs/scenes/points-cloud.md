# Points Cloud

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `points`, `particles`, `galaxy`, `vertex-colors`

Several thousand vertex-colored points arranged as a spiral galaxy, slowly rotating.

## Run it

Open the launcher and pick **Points Cloud**, or deep-link straight to it:

```
http://localhost:5173/#points-cloud
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
