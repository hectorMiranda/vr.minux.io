# UI Color Picker

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `slider`, `color`, `hsl`

Hue and saturation sliders that tint a sphere in real time.

## Run it

Open the launcher and pick **UI Color Picker**, or deep-link straight to it:

```
http://localhost:5173/#ui-color-picker
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
