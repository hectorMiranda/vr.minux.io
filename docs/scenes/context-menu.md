# Context Menu

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `menu`, `context`, `radial`

A context menu that opens near a clicked object, cycling through actions.

## Run it

Open the launcher and pick **Context Menu**, or deep-link straight to it:

```
http://localhost:5173/#context-menu
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
