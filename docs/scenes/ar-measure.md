# AR Measure

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `measure`, `distance`, `hit-test`, `label`

Place two points with select to draw a line and display the distance in meters between them.

## Run it

Open the launcher and pick **AR Measure**, or deep-link straight to it:

```
http://localhost:5173/#ar-measure
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
