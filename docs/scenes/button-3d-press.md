# 3D Button Press

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `button`, `press`, `poke`, `controller`

Physical 3D buttons that depress when poked and emit a click event.

## Run it

Open the launcher and pick **3D Button Press**, or deep-link straight to it:

```
http://localhost:5173/#button-3d-press
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
