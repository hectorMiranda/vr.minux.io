# Rotate Handle

**Category:** Interaction &middot; **XR:** vr &middot; **Tags:** `rotate`, `handle`, `gizmo`, `controller`

A box with a ring handle you grab to rotate it around the Y axis.

## Run it

Open the launcher and pick **Rotate Handle**, or deep-link straight to it:

```
http://localhost:5173/#rotate-handle
```

## What this verifies

Verifies ray, grab, and hover interaction against scene objects using the controllers.
