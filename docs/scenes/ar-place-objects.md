# AR Place Objects

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `placement`, `hit-test`, `robot`, `primitives`

Tap to place a tiny procedural robot at the hit-test reticle; keep multiple placed objects.

## Run it

Open the launcher and pick **AR Place Objects**, or deep-link straight to it:

```
http://localhost:5173/#ar-place-objects
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
