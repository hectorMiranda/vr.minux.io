# 3D Analog Clock

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `clock`, `time`, `analog`

A working 3-D analog clock whose hands track the real wall-clock time.

## Run it

Open the launcher and pick **3D Analog Clock**, or deep-link straight to it:

```
http://localhost:5173/#clock-3d
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
