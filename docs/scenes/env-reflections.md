# Env Reflections

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `pmrem`, `envmap`, `reflections`, `ibl`

PMREM environment generated from a procedural equirect gradient canvas; two rows of spheres vary roughness and metalness.

## Run it

Open the launcher and pick **Env Reflections**, or deep-link straight to it:

```
http://localhost:5173/#env-reflections
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
