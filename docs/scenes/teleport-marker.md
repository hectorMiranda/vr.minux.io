# Teleport Marker

**Category:** Locomotion &middot; **XR:** vr &middot; **Tags:** `teleport`, `locomotion`, `marker`, `normal`

Landing marker styles (ring + normal alignment) on uneven blocks with a sweeping arc indicator.

## Run it

Open the launcher and pick **Teleport Marker**, or deep-link straight to it:

```
http://localhost:5173/#teleport-marker
```

## What this verifies

Verifies a locomotion technique and its comfort behaviour by moving the camera rig rather than the camera.
