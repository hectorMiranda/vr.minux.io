# Controller Haptics

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `haptics`, `rumble`, `input`

Buttons that fire haptic pulses of varying intensity and duration; visual flash confirms each pulse.

## Run it

Open the launcher and pick **Controller Haptics**, or deep-link straight to it:

```
http://localhost:5173/#controller-haptics
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
