# Hand Menu

**Category:** Hands &middot; **XR:** vr &middot; **Tags:** `hands`, `menu`, `palm`, `ui`, `hand-tracking`

Shows a radial menu above the left palm when it faces the user; auto-shows on desktop.

## Run it

Open the launcher and pick **Hand Menu**, or deep-link straight to it:

```
http://localhost:5173/#hand-menu
```

## What this verifies

Checks WebXR hand-tracking: 25-joint poses, pinch detection, and graceful fallback when hands are unavailable.
