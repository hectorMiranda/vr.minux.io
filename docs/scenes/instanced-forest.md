# Instanced Forest

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `instancing`, `instancedmesh`, `forest`, `wind`

Hundreds of low-poly instanced trees with gentle wind-sway animation.

## Run it

Open the launcher and pick **Instanced Forest**, or deep-link straight to it:

```
http://localhost:5173/#instanced-forest
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
