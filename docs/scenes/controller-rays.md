# Controller Rays

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `ray`, `input`

Both controllers cast colored ray lines; a canvas label reports which hands are connected.

## Run it

Open the launcher and pick **Controller Rays**, or deep-link straight to it:

```
http://localhost:5173/#controller-rays
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
