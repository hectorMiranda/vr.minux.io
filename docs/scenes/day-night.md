# Day-Night Cycle

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `day-night`, `lighting`, `sky`, `time-of-day`

A scene cycles through dawn, noon, dusk, and night over 24 s; lighting, sky colour, stars, and moon all animate smoothly.

## Run it

Open the launcher and pick **Day-Night Cycle**, or deep-link straight to it:

```
http://localhost:5173/#day-night
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
