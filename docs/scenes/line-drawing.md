# Line Drawing

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `line`, `lissajous`, `procedural`

An animated Lissajous figure drawn with THREE.Line updating its buffer each frame.

## Run it

Open the launcher and pick **Line Drawing**, or deep-link straight to it:

```
http://localhost:5173/#line-drawing
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
