# Thumbstick Readout

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `thumbstick`, `axes`, `input`

Shows a 2D crosshair panel tracking thumbstick x/y for each controller; auto-circles on desktop.

## Run it

Open the launcher and pick **Thumbstick Readout**, or deep-link straight to it:

```
http://localhost:5173/#thumbstick-readout
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
