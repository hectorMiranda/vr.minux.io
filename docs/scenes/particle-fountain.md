# Particle Fountain

**Category:** Effects &middot; **XR:** vr &middot; **Tags:** `particles`, `fountain`, `additive`, `gravity`

A particle fountain with gravity, respawn, additive blending, and color-over-life from blue to white.

## Run it

Open the launcher and pick **Particle Fountain**, or deep-link straight to it:

```
http://localhost:5173/#particle-fountain
```

## What this verifies

Validates a real-time effect (particles, trails, soft-body or physics) under the XR render loop.
