# Parametric Surface

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `parametric`, `surface`, `ripple`, `animation`

An animated ripple surface generated with ParametricGeometry, rebuilt each frame.

## Run it

Open the launcher and pick **Parametric Surface**, or deep-link straight to it:

```
http://localhost:5173/#parametric-surface
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
