# Billboard Sprites

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `sprite`, `billboard`, `canvas`

Canvas-painted sprite circles that always face the camera and gently bob.

## Run it

Open the launcher and pick **Billboard Sprites**, or deep-link straight to it:

```
http://localhost:5173/#billboard-sprites
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
