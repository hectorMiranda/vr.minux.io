# Skybox Gradient

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `sky`, `gradient`, `shader`, `time-of-day`

An inverted sphere with a GLSL sky shader cycles through dawn, noon, dusk, and night with an animated sun disc and horizon glow.

## Run it

Open the launcher and pick **Skybox Gradient**, or deep-link straight to it:

```
http://localhost:5173/#skybox-gradient
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
