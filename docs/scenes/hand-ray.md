# Hand Ray

**Category:** Hands &middot; **XR:** vr &middot; **Tags:** `hands`, `ray`, `pointing`, `hand-tracking`

Casts a ray from the hand and highlights target spheres when the ray intersects them.

## Run it

Open the launcher and pick **Hand Ray**, or deep-link straight to it:

```
http://localhost:5173/#hand-ray
```

## What this verifies

Checks WebXR hand-tracking: 25-joint poses, pinch detection, and graceful fallback when hands are unavailable.
