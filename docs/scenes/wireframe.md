# Wireframe Toggle

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `wireframe`, `material`, `transparency`

An icosahedron that smoothly fades between solid and wireframe render modes.

## Run it

Open the launcher and pick **Wireframe Toggle**, or deep-link straight to it:

```
http://localhost:5173/#wireframe
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
