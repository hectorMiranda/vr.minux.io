# Teleport Arc

**Category:** Locomotion &middot; **XR:** vr &middot; **Tags:** `teleport`, `locomotion`, `arc`

A floor with scattered pillars; teleport around using a parabolic arc. Desktop shows an animated sweep.

## Run it

Open the launcher and pick **Teleport Arc**, or deep-link straight to it:

```
http://localhost:5173/#teleport-arc
```

## What this verifies

Verifies a locomotion technique and its comfort behaviour by moving the camera rig rather than the camera.
