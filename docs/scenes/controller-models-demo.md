# Controller Models Demo

**Category:** Input &middot; **XR:** vr &middot; **Tags:** `controller`, `model`, `procedural`

Shows a procedural controller model (body + ring + trigger) attached to each grip space.

## Run it

Open the launcher and pick **Controller Models Demo**, or deep-link straight to it:

```
http://localhost:5173/#controller-models-demo
```

## What this verifies

Checks that XR controller input sources — buttons, axes, and target rays — are reported correctly by the runtime.
