# Shadows Demo

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `shadows`, `directional-light`, `pcf`, `shadow-camera`

Multiple objects cast and receive PCFSoft shadows from an orbiting directional light; the shadow-camera helper toggles on/off every 4 s.

## Run it

Open the launcher and pick **Shadows Demo**, or deep-link straight to it:

```
http://localhost:5173/#shadows-demo
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
