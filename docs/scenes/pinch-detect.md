# Pinch Detect

**Category:** Hands &middot; **XR:** vr &middot; **Tags:** `hands`, `pinch`, `gesture`, `hand-tracking`

Detects thumb-index pinch and spawns a marker at the pinch point; auto-demos on desktop.

## Run it

Open the launcher and pick **Pinch Detect**, or deep-link straight to it:

```
http://localhost:5173/#pinch-detect
```

## What this verifies

Checks WebXR hand-tracking: 25-joint poses, pinch detection, and graceful fallback when hands are unavailable.
