# AR Light Estimation

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `light-estimation`, `XRLightProbe`, `lighting`

Drives ambient and directional lights from the XR light estimate; shows estimated intensity; desktop animates a day/night cycle.

## Run it

Open the launcher and pick **AR Light Estimation**, or deep-link straight to it:

```
http://localhost:5173/#ar-light-estimation
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
