# Decals

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `decals`, `decal-geometry`, `addons`, `stickers`

DecalGeometry star splats projected onto a rotating box; falls back to flat textured patches if the addon is unavailable.

## Run it

Open the launcher and pick **Decals**, or deep-link straight to it:

```
http://localhost:5173/#decals
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
