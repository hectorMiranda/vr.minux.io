# Hand Skeleton

**Category:** Hands &middot; **XR:** vr &middot; **Tags:** `hands`, `skeleton`, `bones`, `hand-tracking`

Connects hand joints with line segments forming a full hand skeleton.

## Run it

Open the launcher and pick **Hand Skeleton**, or deep-link straight to it:

```
http://localhost:5173/#hand-skeleton
```

## What this verifies

Checks WebXR hand-tracking: 25-joint poses, pinch detection, and graceful fallback when hands are unavailable.
