# Spatial Audio

**Category:** Audio &middot; **XR:** vr &middot; **Tags:** `audio`, `spatial`, `webaudio`, `panner`, `3d-sound`

An oscillator-driven PositionalAudio source orbits the listener; HRTF panning follows camera position. Starts on first user gesture.

## Run it

Open the launcher and pick **Spatial Audio**, or deep-link straight to it:

```
http://localhost:5173/#spatial-audio
```

## What this verifies

Checks spatialised WebAudio playback and that it resumes correctly after a user gesture.
