# UI Slider

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `slider`, `interaction`

A Slider3D widget that continuously scales a cube from small to large.

## Run it

Open the launcher and pick **UI Slider**, or deep-link straight to it:

```
http://localhost:5173/#ui-slider
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
