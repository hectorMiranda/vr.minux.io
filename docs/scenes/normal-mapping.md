# Normal Mapping

**Category:** Rendering &middot; **XR:** vr &middot; **Tags:** `normals`, `bump`, `tangent`, `lighting`

A procedurally generated normal map (canvas → per-pixel normals) applied to a sphere and plane, lit by an orbiting point light.

## Run it

Open the launcher and pick **Normal Mapping**, or deep-link straight to it:

```
http://localhost:5173/#normal-mapping
```

## What this verifies

Exercises a rendering feature (PBR, shadows, reflections, fog) and how it holds up at stereo XR framerates.
