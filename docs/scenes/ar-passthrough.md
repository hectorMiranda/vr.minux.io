# AR Passthrough

**Category:** AR &middot; **XR:** ar &middot; **Tags:** `ar`, `passthrough`, `transparent`, `alpha`, `floating`

Minimal AR scene: translucent floating cubes rendered over the passthrough camera feed with alpha-blended background.

## Run it

Open the launcher and pick **AR Passthrough**, or deep-link straight to it:

```
http://localhost:5173/#ar-passthrough
```

## What this verifies

Validates an immersive-AR capability (hit-test, anchors, planes, light estimation) over passthrough.
