# Color Grid

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `color`, `grid`, `hsl`

A grid of small cubes sweeping hue (columns) and lightness (rows).

## Run it

Open the launcher and pick **Color Grid**, or deep-link straight to it:

```
http://localhost:5173/#color-grid
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
