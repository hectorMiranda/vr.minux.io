# Smooth Locomotion

**Category:** Locomotion &middot; **XR:** vr &middot; **Tags:** `locomotion`, `smooth`, `thumbstick`

Glide across a tiled plane using thumbstick input; auto-drifts forward on desktop.

## Run it

Open the launcher and pick **Smooth Locomotion**, or deep-link straight to it:

```
http://localhost:5173/#smooth-locomotion
```

## What this verifies

Verifies a locomotion technique and its comfort behaviour by moving the camera rig rather than the camera.
