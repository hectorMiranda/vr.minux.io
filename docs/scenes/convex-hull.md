# Convex Hull

**Category:** Geometry &middot; **XR:** vr &middot; **Tags:** `convex`, `hull`, `geometry`, `points`

A ConvexGeometry built around 30 random points, shown semi-transparent with wireframe overlay.

## Run it

Open the launcher and pick **Convex Hull**, or deep-link straight to it:

```
http://localhost:5173/#convex-hull
```

## What this verifies

Validates procedural geometry generation and that vertex/index buffers upload and animate correctly on the device GPU.
