# Hand Joints

**Category:** Hands &middot; **XR:** vr &middot; **Tags:** `hands`, `joints`, `hand-tracking`

Renders all 25 hand joints as colored spheres; pulses when tracking is active.

## Run it

Open the launcher and pick **Hand Joints**, or deep-link straight to it:

```
http://localhost:5173/#hand-joints
```

## What this verifies

Checks WebXR hand-tracking: 25-joint poses, pinch detection, and graceful fallback when hands are unavailable.
