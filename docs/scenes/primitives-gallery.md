# Primitives Gallery

**Category:** Basics &middot; **XR:** vr &middot; **Tags:** `mesh`, `geometry`, `primitives`

A row of all common Three.js primitives slowly rotating side by side.

## Run it

Open the launcher and pick **Primitives Gallery**, or deep-link straight to it:

```
http://localhost:5173/#primitives-gallery
```

## What this verifies

Confirms basic mesh creation, materials, and the per-frame update loop render correctly both on desktop and inside an immersive session.
