# UI Panel

**Category:** UI &middot; **XR:** vr &middot; **Tags:** `ui`, `panel`, `text`

A rounded backing panel displaying a title and several static text rows.

## Run it

Open the launcher and pick **UI Panel**, or deep-link straight to it:

```
http://localhost:5173/#ui-panel
```

## What this verifies

Verifies spatial UI widgets (panels, buttons, sliders, toggles) render and respond to pointer/controller input.
